# Flourish CV - Professional Resume Builder

A modern, accessible, and user-friendly CV/Resume builder application built with React, TypeScript, and Tailwind CSS.

## 🌟 Features

- **Professional Templates**: Multiple CV templates including Modern Blue, Executive Formal, Academic, Creative Edge, and more
- **Real-time Preview**: See your changes instantly as you type
- **PDF Export**: High-quality PDF generation with template styling preservation
- **Accessibility First**: WCAG 2.1 AA compliant with comprehensive screen reader support
- **Cross-browser Compatible**: Works seamlessly across Chrome, Firefox, Safari, and Edge
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Color Contrast Validation**: Built-in color accessibility checker
- **Auto-save**: Never lose your work with automatic saving

## ♿ Accessibility Features

This application is built with accessibility as a core principle:

- **WCAG 2.1 AA Compliance**: Meets international accessibility standards
- **Screen Reader Support**: Full compatibility with NVDA, JAWS, and VoiceOver
- **Keyboard Navigation**: Complete keyboard accessibility with proper focus management
- **Skip Links**: Quick navigation for keyboard and screen reader users
- **ARIA Labels**: Comprehensive labeling for all interactive elements
- **Color Contrast**: Automatic validation ensures readable text for all users
- **High Contrast Mode**: Support for system high contrast settings
- **Reduced Motion**: Respects user preferences for reduced animations
